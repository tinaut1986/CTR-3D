## How to test (what cost time this session)

- Console: `./build3ds.sh --install 192.168.1.139` (debug build, `CTR_VERSION=0.1.0`). The game restarts: any
  session in progress is lost, and a game stuck in a load restarts only when it gets out of it.
- Drive it with `SITE KEYS` / `TOUCH` / `SHOT` / `STATE` (helper script in the session scratchpad: `ctr.sh IP cmd`).
  Menu navigation is picky: the title screen needs START; in the main menu hold DOWN for 4 frames each
  (a longer hold skips an entry; the cursor starts on ADVENTURE, ARCADE is three presses down, then A);
  screens at 10 fps need holds of 12-20 frames. Check `mode=` in `SITE STATE`: ARCADE is 0x400000, TIME TRIAL
  0x20000 (a time trial has no wumpa, item or driver list).
- Do not poll FTP while measuring a load or race (1-2 s stalls). Read `ctr3ds.log` once, after.
- Log lines for loads: `[LOADPROF]`; for the HUD: none (the layout is deterministic; use `SITE SHOT`).
