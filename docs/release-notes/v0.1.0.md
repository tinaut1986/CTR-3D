- First beta of CTR 3D for the New 3DS, installed as a CIA with the New 3DS extended memory.
- The bottom screen has touch tabs: Status, Map, Options, Updater (and Debug in debug builds).
- New in-game updater: check GitHub for a newer version (stable or + BETAS), read what changed, then download and install it from the Updater tab.
- Developers can send a CIA over FTP and have it installed and restarted from the game.
