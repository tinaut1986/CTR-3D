- First beta of CTR 3D. Installs as a CIA: New 3DS with extended memory, and now also Old 3DS / 2DS (slower).
- Old 3DS / 2DS: menus run near 30 fps, the track select screen plays its preview video at about 12 fps, and loading a race takes a few seconds. Known: the loading screen still pauses briefly and races have hitches.
- The bottom screen has touch tabs: Status, Map, Options, Updater (and Debug in debug builds).
- In-game updater: check GitHub for a newer version (stable or + BETAS), read what changed, then download and install it from the Updater tab.
- Betas include debug tools: an FTP server with remote screenshots, status and input, and an SD log switch in Options.
